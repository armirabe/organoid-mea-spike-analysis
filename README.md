# Organoid MEA Spike Analysis

MATLAB pipeline for detecting and characterising extracellular spikes in
multichannel recordings from cerebral organoids on carbon nanotube
microelectrode arrays.

This is the analysis code behind:

> Mishra, N., Kaveti, R., Liu, P. et al. Carbon nanotube microelectrode arrays
> enable scalable and accessible electrophysiological recordings of cerebral
> organoids. *npj Biosensing* **3**, 20 (2026).
> https://doi.org/10.1038/s44328-026-00088-9

## What it does

Given a multichannel extracellular recording, the pipeline:

1. Scales raw samples to microvolts and applies a zero-phase Butterworth
   bandpass filter (300–6000 Hz) or a 500 Hz highpass.
2. Detects negative-going threshold crossings at `-6σ`, where `σ` is the
   median absolute deviation noise estimate, `median(|x|) / 0.6745`.
3. Extracts a ±2 ms waveform around each spike and measures trough amplitude
   and full width at half minimum.
4. Computes per-channel firing rates two ways — spike count over recording
   duration, and the reciprocal of the mean inter-spike interval.
5. Produces a smoothed firing rate density per channel and a population rate
   over time.
6. Writes a per-channel summary table to an Excel workbook.

## Requirements

MATLAB R2019b or newer, with the Signal Processing Toolbox (`butter`,
`filtfilt`, `highpass`). No other dependencies.

Reading Blackrock `.ns6` files requires the
[NPMK toolbox](https://github.com/BlackrockNeurotech/NPMK), which is not
bundled here.

## Quick start

No recordings are required to try it — the demo generates a surrogate dataset:

```matlab
addpath(genpath('src')); addpath('demo');
run_demo
```

This writes `results/demo_results.xlsx` and draws the standard figure set.

## Using your own data

```matlab
addpath(genpath('src'));

openNSx('my_recording.ns6');        % NPMK; yields the NS6 struct
data = NS6.Data;                     % channels x samples, raw counts

p              = default_params();
p.n_channels   = 12;
p.sf           = 30000;
p.output_file  = 'results/my_recording.xlsx';

[T, S] = analyze_recording(data, p);

timestamps = arrayfun(@(s) s.spk.idx, S, 'UniformOutput', false);
[density, t] = firing_rate_density(timestamps, size(data, 2), p);

plot_results(S, density, t, p);
export_results(T, p);
```

## Parameters

All parameters live in `src/default_params.m`. The ones worth revisiting:

| Parameter | Default | Notes |
|---|---|---|
| `sf` | 30000 | Sampling frequency in Hz |
| `scale_uv` | 0.25 | Blackrock NSx stores 1/4 µV per count |
| `thresh_mult` | 6 | Threshold is `-thresh_mult × σ` |
| `pre_ms` / `post_ms` | 2 / 2 | Waveform window; `post_ms` also sets the refractory skip |
| `filter.type` | `bandpass` | `bandpass`, `highpass`, or `none` |
| `density_bin_s` | 0.01 | Firing rate density bin width |
| `density_sigma_s` | 1.0 | Gaussian smoothing SD for the density |

## Outputs

`analyze_recording` returns a table with one row per channel:

`channel`, `n_spikes`, `mean_duration_ms`, `std_duration_ms`,
`mean_amplitude_uv`, `std_amplitude_uv`, `firing_rate_hz`, `isi_rate_hz`,
`active_spiking_s`.

Firing rates are `NaN` for channels with fewer than two spikes, since a
single spike provides no interval to average.

## Relationship to the published analysis

`src/` is a refactor of the scripts in `legacy/`. Spike detection and the
per-channel metrics are mathematically unchanged. Several
bugs in the legacy scripts causing slow performance were fixed.

## Data availability

No experimental recordings are included in this repository. The demo runs on
synthetic data generated by `demo/synthetic_recording.m`, which is a simple
surrogate and not a biophysical model.
